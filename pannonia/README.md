# Pannonia — a region idea for Anno 117

An early concept by Ádám: **an Albion-inspired Pannonian region for Anno 117: Pax Romana**.

This folder is a home for the idea and its future development. It is a concept, not a playable mod, announced expansion or feature included in the Companion download. No release date is promised.

## The starting idea

The Companion began with a simple wish: spend more time building an empire and less time digging through statistics. My next idea is a little bigger — exploring what a Pannonian region could look and feel like in Anno 117.

Albion is the starting inspiration. The aim would be to develop a distinct regional identity rather than simply rename existing goods and buildings. Exactly how far this can go depends on the game's modding capabilities and the work involved.

## What is established so far

- The working name is **Pannonia**.
- The idea is a new region concept for **Anno 117: Pax Romana**.
- **Albion** provides the initial inspiration.
- This is a personal community project idea, separate from the working Companion application.

Everything beyond these points is open for discussion and research.

## Questions to explore

- What should make the region feel recognizably Pannonian?
- Which landscape, settlement and architectural references should guide it?
- Which goods, needs and production chains would create interesting decisions?
- How should the region interact with Latium and Albion?
- Which specialists, characters and stories would fit?
- What can the available modding tools actually support, and what would be a sensible first playable scope?

These are design questions, not confirmed features. Historical references and technical feasibility should be documented before they become part of the proposal.

## How this folder can grow

As the idea takes shape, this directory can hold researched references, design notes, production-chain sketches, original concept artwork and small technical experiments. Each should distinguish proposals from verified information and record sources or asset ownership where relevant.

For now, this README is the starting point. There are no mod installation instructions because there is no playable Pannonia build yet.
