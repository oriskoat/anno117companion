# Anno 117 Companion 0.30.0

## Search and plan from the same dashboard

- **Find anything faster.** Press **Ctrl+F** or use the search button to jump to goods, production chains, islands, trade routes, population tiers, specialists, deities or a Companion page.
- **Compare settlements at a glance.** Each candidate shows what changes compared with your selected island, including local chains, building demand, imports and missing sources. Recommended production islands show where each good goes and the amount to ship.
- **Read deity bonuses from your save.** The Companion shows the dominant deity, active wonder bonuses and current and upcoming local milestones. All 11 deity portraits are included. Island belief and empire-wide belief each have their own value.
- **Use additional output.** Island-specific chains show by-products from recorded effects. The Supply Optimiser credits additional output from proposed builds before sizing separate capacity. The inventory simulation ties that output to the producer's operating rate and inputs. For existing joint production, the planner keeps linked groups running when the reported totals cannot be attributed to individual producers.
- **Navigate the planning views more easily.** Production Chains has region and tier shortcuts. Routes has cargo previews and search. The Supply Optimiser surfaces build, ship and reduce actions and the checks that need attention.

## Install or update

Use **More → Updates** on Windows or Android. For a fresh install, see the [setup guide](SETUP.md) or [Einrichtung auf Deutsch](SETUP.de.md). Use the matching Windows release as the host for Live and Save Insights on Android and other paired devices.

Everything remains free. The Companion reads game data and prepares plans locally. The game reports aggregated production, so the exact loss from stopping an existing joint producer remains uncertain.
