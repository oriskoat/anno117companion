# Anno 117 Companion 0.29.0 — Settlement Planner

Plan settlements around a population branch and the goods it will need. Use a campaign save with **Use save data** enabled, then open **Home → Settlement Planner**. On smaller screens the planner is also available under **More**.

- **Choose a long-term target.** Compare islands in Latium, Albion and Aegyptus where present in the selected save. The planner includes starting tiers and the selected branch up to its final tier. On developed islands it shows the progress it sees in the save.
- **Plan the expansion.** Review a recommended second island and branch, and a possible production island for remaining gaps. Expand the trade connections to see the goods and transfer a proposal to Routes.
- **Review the production plan.** Build, Ship and Reduce cards summarize the proposed actions. Expand a card to inspect calculations and seasonal targets where applicable.
- **Keep usable statistics.** An empty pipe update preserves the last usable rates and their original timestamp. The matching save supplies rates when usable pipe data are unavailable.

Settlement plans use nominal recipes and a configurable residence target. Confirm terrain, unlocks, weather, specialist coverage and shipping in game. Review the first two islands’ routes against the production-island proposal before transferring cargo. Save any open Routes draft before opening a new proposal. Android downloads include the new dashboard. Use the matching Windows Companion as the LAN host for the full feature set.

Use **More → Updates** on Windows and Android, or see the [setup guide](SETUP.md) for a fresh installation.
