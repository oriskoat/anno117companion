# Shared chains and contextual navigation — 0.26.0 beta 6

Free local Windows beta. No GitHub publication or Android APK build is part of this iteration. Mobile browser layouts share the dashboard source.

## Balanced chains first

Chains show their balanced building ratios and product icons immediately. Parallel ingredients share a row; arrows show dependency levels. Fuel capacity is rounded separately from the primary balanced ratio. Regional producer alternatives remain available, including both valid gold routes where configured.

Expand a card to change eligible water/aqueduct connections, silos or Dovecotes, granary size, supported specialist base effects, deity and belief. Card and detailed panel use one state: changing either updates both. Scenarios are separate per good and region. The default is nominal 100% production without a seasonal bonus; Aegyptus can also preview dry, flood or full Nile cycle average output.

The comparison normalizes both setups to the same final output and shows rounded producer counts, base workforce requirements and input rates. Support ingredients are included. Workforce modifiers, conditional specialist boosts and recipe substitutions are not certified. Byproducts are not automatically credited against other chains. Seasonal averages require buffers.

Choose a compatible island to preview these assumptions in the full planner. Only explicit assumptions are forwarded; recorded current output remains the existing-capacity anchor. The planner evaluates its configured full forecast, not just a catalogue dry-season preview. Uniform recorded owner links may be imported explicitly. Mixed coverage, granary radius estimates, ownership, fertility, deposits, unlocks and regional deity availability require verification.

## Source controls and automatic matching

Choose different save is in the upper control bar. Campaign, save time and source details use a compact expandable line. The chooser offers latest or specific discovered saves, plus automatic or manual mode. Albion Home cards no longer display a count of recorded water links as their headline.

Automatic mode requires fresh server-owned pipe statistics. Campaign labels shortlist candidates; island IDs, names and regions must establish a unique match. At most four same-label campaigns are read, with cached unchanged results. An unreadable competing candidate or ambiguity requires manual selection. The chosen campaign follows its latest save: this does not prove it is the exact file loaded in game. Stale pipe evidence retains the current save and shows that matching is waiting. Manual selection remains authoritative until automatic mode is enabled. Multiplayer ambiguity requires a player selection.

Save reading remains local and read-only. The bridge only accepts discovered profiles/files; no browser-provided arbitrary filesystem path is read.

## Navigation and page roles

Home summarizes regional conditions and important issues. Selecting a product opens its contextual product detail, with separate Find supply, Plan changes and View island actions. Islands describe locations; Products compare goods; Supply finds transfers; Chains explains recipes; Needs describes population requirements; Routes holds shipping plans; Planner evaluates coordinated changes.

Back navigation restores the originating page, filters, island/product context and scroll position. Browser Back and the in-app Back button share this journey. Campaign changes invalidate older campaign-specific details. Snapshot/save/route polling continues to preserve the open interface while data refreshes in the background.
