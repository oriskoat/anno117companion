# Compact chain controls - 0.26.1 beta 7

Local Windows beta only. No APK build or GitHub publication.

Each producer now has a collapsed row with its product icon, building name and selected water/module/granary/specialist badges. Base setups use one short label. Open a row to edit its controls; edits retain the open row and remain synchronized with the card/detail panel. Scope/season, deity/belief and methodology have separate disclosures. None fields remain inside the relevant open producer instead of filling the whole page.

A sticky result panel shows the chain at the same final output as the base setup, rounded producer counts, total base workforce and module-feed demand. Detailed workforce types and input comparisons remain available in Compare. Inputs and season assumptions retain the limitations in BETA_026.md. All other beta-6 functions remain unchanged.

The fixed Desktop shortcut launches ../Anno117Companion-Beta/Anno117Companion.exe. No user settings are reset.
